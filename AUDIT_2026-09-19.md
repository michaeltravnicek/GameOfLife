## Needs a decision (not changed)

Security
- Registration adopts an archive player on an **unverified e-mail** → inherits points/history. Fix first: verify e-mail before adoption, or admin-only merge.
- Account deletion without password re-entry.
- Feedback allowed without attendance, including future events.
- Google sign-in starts on GET (`SOCIALACCOUNT_LOGIN_ON_GET`), allauth's login-CSRF trade-off.
- HSTS 300 s / no includeSubDomains / no preload — deliberate ramp.

Performance
- Confirm `REDIS_URL` on Render; consider making its absence fatal.
- `events_list` is `@never_cache`; `Vary: Cookie` + public max-age would edge-cache the anonymous variant (mind cache poisoning).
- Six `date__date__gte/lte` filters cast the column and bypass the new index; use `date__gte=start, date__lt=end+1day`.
- Profile/player pages: 2 queries per season.
- Fonts ship as raw TTF (2.6 MB); WOFF2 ≈ half. Helvetica licence + no converter here.
- Dead `cities_cached` + cache key (would leak hidden events' places if wired up).
- Admin feedback endpoint unbounded.
- Edit-profile fetches `/me` then profile although AuthContext has the user.
